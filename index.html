AutoAllow 隐私政策

最后更新: 2026 年 10 月 25 日

AutoAllow 是一个 Windows 工具, 只针对你选择的窗口和会话, 自动确认 Claude Code (控制台窗口) 和 Claude Desktop 的权限提示。本政策说明本程序会处理哪些信息。

概要

AutoAllow 不收集你的个人信息, 不把任何数据存到服务器, 不出售也不与他人共享。所有处理都在你自己的电脑上完成, 程序不会进行任何网络连接。

程序会读取什么

为了发现权限提示, AutoAllow 会读取你选择监控的控制台窗口当前显示的文字, 以及通过 Windows 无障碍接口 (UI Automation) 读取 Claude Desktop 的界面内容。这些文字只在你的电脑内存中处理, 不会发送到任何地方。

程序会做什么

在你选择的窗口或会话中发现权限提示时, 程序会在该控制台窗口按下回车键, 或在 Claude Desktop 中点击 "Allow once" 按钮。当你点击对应按钮时, 它还可以开启无障碍选项重新启动 Claude Desktop。

保存在你电脑上的数据

AutoAllow 会在本地应用数据目录 (%LOCALAPPDATA%) 下的 AutoAllow 文件夹里按天保存运行日志, 另有一个记录语言选择的小设置文件。日志中可能包含窗口标题、Claude Desktop 会话标题和已处理提示的简短片段。这些文件不会离开你的电脑, 你可以随时删除, 卸载程序时也会一并删除。

网络、统计和广告

AutoAllow 不连接互联网, 不包含任何统计分析、崩溃上报、跟踪或广告, 也不需要注册账号。

第三方

AutoAllow 不与任何人共享数据。如果你从 Microsoft Store 安装, Microsoft 可能会依据其自身的隐私声明收集下载和安装相关的信息。AutoAllow 是独立工具, 与 Anthropic 没有关联, 也未获得其认可。Claude 是 Anthropic 的商标。

儿童

AutoAllow 是开发者工具, 不面向 13 岁以下儿童。

政策变更

如本政策有变更, 更新后的版本会发布在本页面并注明新的日期。

联系方式

如对本政策有疑问, 请联系: shentuqc@outlook.com

AutoAllow Privacy Policy

Last updated: October 25, 2026

AutoAllow is a Windows utility that automatically confirms permission prompts from Claude Code (in console windows) and Claude Desktop, only for the windows and sessions you choose. This policy explains what information the app handles.

Summary

AutoAllow does not collect, store on any server, sell, or share your personal information. Everything happens on your own computer. The app makes no network connections.

What the app reads

To detect permission prompts, AutoAllow reads the text currently shown in the console windows you choose to monitor, and the on-screen interface of Claude Desktop through the Windows accessibility interface (UI Automation). This text is processed in memory, on your computer only, and is never sent anywhere.

What the app does

When it finds a permission prompt in a window or session you selected, it presses Enter in that console window or clicks the "Allow once" button in Claude Desktop. It can also restart Claude Desktop with its accessibility option enabled when you click the corresponding button.

Data stored on your computer

AutoAllow keeps a daily activity log in the AutoAllow folder under your local application data (%LOCALAPPDATA%), and a small settings file with your language choice. The log can contain window titles, Claude Desktop session titles and short excerpts of the prompts that were handled. These files never leave your computer. You can delete them at any time, and they are removed when you uninstall the app.

Network, analytics and advertising

AutoAllow does not connect to the internet. It contains no analytics, crash reporting, tracking or advertising, and does not require an account.

Third parties

AutoAllow does not share data with anyone. If you install it from the Microsoft Store, Microsoft may collect information about the download and installation under its own privacy statement. AutoAllow is an independent tool and is not affiliated with or endorsed by Anthropic. Claude is a trademark of Anthropic.

Children

AutoAllow is a developer tool and is not directed at children under 13.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new date.

AutoAllow 개인정보 처리방침

최종 업데이트: 2026년 10월 25일

AutoAllow는 사용자가 선택한 창과 세션에 한해 Claude Code(콘솔 창)와 Claude Desktop의 권한 프롬프트를 자동으로 확인하는 Windows 유틸리티입니다. 이 방침은 앱이 어떤 정보를 처리하는지 설명합니다.

요약

AutoAllow는 개인정보를 수집하거나, 어떤 서버에도 저장하거나, 판매하거나, 공유하지 않습니다. 모든 작업은 사용자의 컴퓨터에서만 이루어지며, 앱은 네트워크에 연결하지 않습니다.

앱이 읽는 내용

권한 프롬프트를 감지하기 위해 AutoAllow는 사용자가 모니터링하도록 선택한 콘솔 창에 현재 표시된 텍스트와, Windows 접근성 인터페이스(UI Automation)를 통해 Claude Desktop의 화면 내용을 읽습니다. 이 텍스트는 사용자의 컴퓨터 메모리에서만 처리되며 어디로도 전송되지 않습니다.

사용자가 선택한 창이나 세션에서 권한 프롬프트를 발견하면 해당 콘솔 창에서 Enter를 누르거나 Claude Desktop에서 "Allow once" 버튼을 클릭합니다. 또한 사용자가 해당 버튼을 클릭하면 접근성 옵션을 켠 상태로 Claude Desktop을 다시 시작할 수도 있습니다.

AutoAllow는 인터넷에 연결하지 않습니다. 분석, 충돌 보고, 추적, 광고 기능이 전혀 없으며 계정도 필요하지 않습니다.

Você pode excluí-los a qualquer momento, e eles são removidos quando você desinstala o aplicativo.

Rede, análises e publicidade

O AutoAllow não se conecta à internet. Ele não contém análises, relatórios de falhas, rastreamento nem publicidade, e não exige uma conta.

Terceiros

O AutoAllow não compartilha dados com ninguém. Se você o instalar pela Microsoft Store, a Microsoft pode coletar informações sobre o download e a instalação de acordo com a sua própria declaração de privacidade. O AutoAllow é uma ferramenta independente, sem afiliação com a Anthropic nem endosso dela. Claude é uma marca registrada da Anthropic.

Crianças

O AutoAllow é uma ferramenta para desenvolvedores e não é direcionado a crianças menores de 13 anos.

Политика конфиденциальности AutoAllow

Последнее обновление: 25 октября 2026 г.

AutoAllow — это утилита для Windows, которая автоматически подтверждает запросы разрешений Claude Code (в окнах консоли) и Claude Desktop только для выбранных вами окон и сеансов. В этой политике объясняется, какую информацию обрабатывает приложение.

Кратко

AutoAllow не собирает, не хранит на каких-либо серверах, не продаёт и не передаёт вашу личную информацию. Всё происходит на вашем компьютере. Приложение не устанавливает сетевых подключений.

Что читает приложение

Чтобы обнаруживать запросы разрешений, AutoAllow читает текст, который в данный момент отображается в выбранных вами для мониторинга окнах консоли, а также содержимое интерфейса Claude Desktop на экране через интерфейс специальных возможностей Windows (UI Automation). Этот текст обрабатывается в памяти, только на вашем компьютере, и никуда не отправляется.

Что делает приложение

Обнаружив запрос разрешения в выбранном вами окне или сеансе, приложение нажимает Enter в этом окне консоли или нажимает кнопку "Allow once" в Claude Desktop. Оно также может перезапустить Claude Desktop с включённой опцией специальных возможностей, когда вы нажимаете соответствующую кнопку.

Данные, хранящиеся на вашем компьютере

AutoAllow ведёт ежедневный журнал работы в папке AutoAllow в локальных данных приложений (%LOCALAPPDATA%), а также небольшой файл настроек с выбранным вами языком. Журнал может содержать заголовки окон, названия сеансов Claude Desktop и короткие фрагменты обработанных запросов. Эти файлы никогда не покидают ваш компьютер. Вы можете удалить их в любой момент, а при удалении приложения они удаляются автоматически.

Сеть, аналитика и реклама

AutoAllow не подключается к интернету. В нём нет аналитики, отчётов о сбоях, отслеживания и рекламы, а учётная запись не требуется.

Третьи лица

AutoAllow не передаёт данные никому. Если вы устанавливаете его из Microsoft Store, Microsoft может собирать сведения о загрузке и установке в соответствии со своим заявлением о конфиденциальности. AutoAllow — независимый инструмент, не связанный с Anthropic и не одобренный ею. Claude — товарный знак Anthropic.

Дети

AutoAllow — инструмент для разработчиков, он не предназначен для детей младше 13 лет.
