AutoAllow 是什么

Claude Code 和 Claude Desktop 在执行命令、修改文件之前会弹出权限提示, 等你确认。AutoAllow 可以替你确认你选定的窗口和会话里的这些提示, 让 AI 助手不必停下来等你。

  • Claude Code (命令提示符、PowerShell、Windows 终端): 出现 "Do you want to proceed?" 提示时按回车, 也就是选择默认的 "1. Yes"。
  • Claude Desktop: 出现权限确认框时点击 "Allow once"。

确认提示就等于允许助手执行它请求的命令或操作。请只监控你信任其工作内容的会话。

开始之前

  • 需要 Windows 10 (1809) 或更高版本。
  • Claude Code 需要运行在命令提示符 (cmd)、Windows PowerShell 或 PowerShell 7 中, 用传统控制台窗口或 Windows 终端都可以。
  • Claude Desktop 需要从 Microsoft Store 安装, 并以无障碍模式运行 (见下文)。
  • AutoAllow 识别的是 Claude 英文界面上的提示和按钮文字。如果 Claude 使用其他界面语言, 可能无法识别。

界面概览

  • 检测到的目标: 列出正在运行 Claude Code 的控制台窗口, 以及运行中或等待确认的 Claude Desktop 会话。勾选"显示全部"可以看到所有控制台和闲置会话。列表每 3 秒自动刷新, 也可以点"刷新列表"。
  • 状态列显示"● 监控中"的行正在被监控。
  • 检查间隔: 多久检查一次屏幕, 默认 0.3 秒。重复按键冷却: 同一个提示一直没消失时, 两次操作之间至少间隔几秒。
  • Claude Desktop 区域: 显示 Claude Desktop 的状态, 以及以无障碍模式重启的按钮。
  • 日志: 每次确认、跳过或出错都会记录在这里。绿色表示成功, 红色表示出错或需要注意。
  • 右下角"语言": 选择界面语言, 重启程序后生效。

监控 Claude Code 控制台窗口

  1. 在控制台窗口里正常启动 Claude Code。
  2. 回到 AutoAllow, 在列表里找到这个窗口 (类型为 CMD, 可以按窗口标题和最后一行文字辨认)。
  3. 选中它, 点击"开始监控选中", 或者直接双击这一行。按住 Ctrl 或 Shift 可以一次选多个。
  4. 状态变成"● 监控中"后, 这个窗口再出现确认提示时, AutoAllow 会自动按回车, 并在日志里记一条。

要停止, 选中这一行点"停止选中", 或点"全部停止"。手动停止过的窗口不会再被自动监控。

监控 Claude Desktop

  1. 确认 Claude Desktop 区域显示"已以无障碍模式运行, 可以监控"。如果显示没开无障碍模式, 点"以无障碍模式重启"。这会关闭并重新打开 Claude Desktop, 请先等手头的对话告一段落。
  2. 在列表里选中要监控的会话 (类型为"桌面版"), 点"开始监控选中"。想让所有等待确认的会话都自动处理, 可以开启"检测到等待确认时自动监控" (见下文)。
  3. 之后这些会话弹出权限确认框时, AutoAllow 会自动点击 "Allow once"。

勾选"后台 session 等待确认时, 自动切换过去处理再切回"后, 如果被监控的会话不在当前画面里, AutoAllow 会切换到那个会话, 确认后再切回原来的会话。处理时 Claude Desktop 窗口可能会短暂跳到最前面。

如果显示"可以监控, 但窗口被挡住时会漏检", 建议在空闲时点一次"以无障碍模式重启", 这样 Claude Desktop 被其他窗口挡住时也能正常检测。

自动监控等待确认的窗口 (默认关闭)

勾选"检测到等待确认时自动监控"后, 只要有 Claude Code 窗口或 Claude Desktop 会话在等待确认, AutoAllow 就会自动开始监控并替你确认, 包括你没有手动选择的窗口和会话。开启时会弹出确认框, 你的选择会被记住。

这个选项会确认所有新出现的提示。只有在你信任所有会话的工作内容时才开启。

只检测不操作

勾选"只检测不操作 (dry-run)"后再开始监控, AutoAllow 只在日志里记录检测到的提示, 不按键、不点击。可以先用它看看会确认哪些操作。这个选项在开始监控时生效, 修改后需要停止再重新开始监控。

托盘和退出

点击窗口的关闭按钮时, AutoAllow 会缩小到系统托盘, 监控继续运行。双击托盘图标可以重新打开窗口; 右键托盘图标选"退出"才会真正退出并停止所有监控。

日志和设置文件

日志按天保存在 %LOCALAPPDATA%\AutoAllow\logs, 设置 (界面语言、是否自动监控) 保存在 %LOCALAPPDATA%\AutoAllow\settings.json。这些文件只在你的电脑上, 卸载时会一起删除。

AutoAllow 的功能

Claude Code 與 Claude Desktop 在執行命令或修改檔案之前，會顯示權限提示並等待你確認。AutoAllow 會在你選定的視窗與工作階段中代為確認這些提示，讓 AI 助理不必停下來等待。

  • Claude Code（命令提示字元、PowerShell、Windows Terminal）：出現 「Do you want to proceed?」 提示時，會按下 Enter，也就是選擇預設的 「1. Yes」。
  • Claude Desktop：出現權限對話方塊時，會點擊 「Allow once」。

確認提示就等於讓助理執行它所要求的命令或操作。請只監控你信任其工作內容的工作階段。

開始之前

  • 需要 Windows 10（1809 版）或更新版本。
  • Claude Code 必須在命令提示字元（cmd）、Windows PowerShell 或 PowerShell 7 中執行，可以是傳統主控台視窗，也可以是 Windows Terminal。
  • Claude Desktop 必須是從 Microsoft Store 安裝，並以協助工具模式執行（見下文）。
  • AutoAllow 辨識的是 Claude 英文介面的提示與按鈕文字。如果 Claude 使用其他顯示語言，可能無法辨識提示。

主視窗

  • 偵測到的目標：執行 Claude Code 的主控台視窗，以及正在執行或等待確認的 Claude Desktop 工作階段。勾選 「顯示全部」 可看到所有主控台與閒置的工作階段。清單每 3 秒更新一次，也可以按 「重新整理」。
  • 「狀態」 欄顯示 「● 監控中」 的列，表示正在被監控。
  • 檢查間隔：檢查畫面的頻率（預設為 0.3 秒）。重複冷卻時間：同一個提示一直停留在畫面上時，兩次動作之間至少要間隔的秒數。
  • Claude Desktop 區域：顯示 Claude Desktop 的狀態，並提供以協助工具模式重新啟動它的按鈕。
  • 記錄：每一次確認、略過或錯誤都會記錄在這裡。綠色代表成功；紅色代表錯誤或需要檢查的事項。
  • 「語言」（右下角）：選擇顯示語言。重新啟動應用程式後生效。

監控 Claude Code 主控台視窗

  1. 照常在主控台視窗中啟動 Claude Code。
  2. 在 AutoAllow 的清單中找到該視窗（類型為 CMD；可以用視窗標題與最後一行來區分不同視窗）。
  3. 選取該視窗後按 「監控選取項目」，或在該列上按兩下。按住 Ctrl 或 Shift 可選取多個。
  4. 狀態變成 「● 監控中」 後，只要該視窗出現確認提示，AutoAllow 就會按下 Enter，並在記錄中寫入一行。

要停止時，選取該列後按 「停止選取項目」，或按 「全部停止」。你手動停止的視窗不會再被自動監控。

監控 Claude Desktop

  1. 確認 Claude Desktop 區域顯示 「已使用協助工具模式執行，可開始監控」。如果顯示未使用協助工具模式，請按 「以協助工具模式重新啟動」。這會關閉並重新開啟 Claude Desktop，請先完成手邊的工作。
  2. 在清單中選取要監控的工作階段（類型為 Desktop）後按「監控選取項目」。若要自動處理所有等待中的工作階段，請開啟「有提示等待時自動監控」（見下文）。
  3. 此後，只要這些工作階段出現權限對話方塊，AutoAllow 就會點擊 「Allow once」。

勾選 「背景工作階段有提示等待時，切換過去處理後再切換回來」 後，如果被監控的工作階段不是目前顯示在畫面上的那個，AutoAllow 會切換過去、確認提示，再切換回來。這段期間 Claude Desktop 視窗可能會短暫跳到最前面。

如果顯示 「可以監控，但視窗被遮住時可能漏掉提示」，請在方便時按一次 「以協助工具模式重新啟動」，這樣即使其他視窗蓋住 Claude Desktop，也能偵測到提示。

自動監控等待中的提示（預設關閉）

勾選 「有提示等待時自動監控」 後，只要有 Claude Code 視窗或 Claude Desktop 工作階段正在等待確認，AutoAllow 就會開始監控並代為確認，包括你沒有選取的視窗與工作階段。開啟時會請你確認，你的選擇會被記住。

這個選項會確認每一個新的提示。只有在你信任所有工作階段的工作內容時才開啟。

僅偵測

在開始監控之前勾選 「僅偵測（試執行）」，AutoAllow 只會把找到的提示寫入記錄，不會按鍵或點擊。可以用它來查看哪些提示會被確認。這個選項在開始監控時套用；變更後，請先停止再重新開始監控。

系統匣與結束

按視窗的關閉按鈕會把 AutoAllow 縮小到系統匣，監控會繼續執行。在系統匣圖示上按兩下可重新開啟視窗。要結束並停止所有監控，請在系統匣圖示上按右鍵，選擇 「結束」。

記錄與設定檔

每日記錄儲存在 %LOCALAPPDATA%\AutoAllow\logs，設定（顯示語言、自動監控）儲存在 %LOCALAPPDATA%\AutoAllow\settings.json。這些檔案只會保留在你的電腦上，並會在解除安裝應用程式時移除。

What AutoAllow does

Before running a command or changing files, Claude Code and Claude Desktop show a permission prompt and wait for you. AutoAllow confirms these prompts for you in the windows and sessions you choose, so the AI assistant doesn't have to stop and wait.

  • Claude Code (Command Prompt, PowerShell, Windows Terminal): when the "Do you want to proceed?" prompt appears, it presses Enter, which picks the default "1. Yes".
  • Claude Desktop: when a permission dialog appears, it clicks "Allow once".

Confirming a prompt lets the assistant run the command or action it asked for. Only monitor sessions whose work you trust.

Before you start

  • Windows 10 (version 1809) or later is required.
  • Claude Code must run in Command Prompt (cmd), Windows PowerShell or PowerShell 7, in a classic console window or in Windows Terminal.
  • Claude Desktop must be installed from the Microsoft Store and run in accessibility mode (see below).
  • AutoAllow recognizes the prompt and button text of Claude's English interface. If Claude uses another display language, prompts may not be recognized.

The main window

  • Detected targets: console windows running Claude Code, and Claude Desktop sessions that are running or waiting for confirmation. Check "Show all" to see every console and idle session. The list refreshes every 3 seconds, or click "Refresh".
  • Rows marked "● Monitoring" in the Status column are being monitored.
  • Check interval: how often the screen is checked (0.3 seconds by default). Repeat cooldown: the minimum number of seconds between two actions while the same prompt stays on screen.
  • Claude Desktop area: shows the state of Claude Desktop, with a button to restart it in accessibility mode.
  • Log: every confirmation, skip or error is recorded here. Green means success; red means an error or something to check.
  • "Language" (bottom right): choose the display language. It takes effect after you restart the app.

Monitor a Claude Code console window

  1. Start Claude Code in a console window as usual.
  2. In AutoAllow, find the window in the list (type CMD; you can tell windows apart by title and last line).
  3. Select it and click "Monitor selected", or double-click the row. Hold Ctrl or Shift to select several.
  4. Once the status shows "● Monitoring", AutoAllow presses Enter whenever a confirmation prompt appears in that window and writes a line to the log.

To stop, select the row and click "Stop selected", or click "Stop all". A window you stopped by hand is not monitored automatically again.

Monitor Claude Desktop

  1. Make sure the Claude Desktop area says "Running in accessibility mode, ready to monitor". If it says accessibility mode is off, click "Restart in accessibility mode". This closes and reopens Claude Desktop, so finish what you are doing first.
  2. Select the sessions to monitor in the list (type Desktop) and click "Monitor selected". To have every waiting session handled automatically, turn on "Auto-monitor when a prompt is waiting" (see below).
  3. From then on, when those sessions show a permission dialog, AutoAllow clicks "Allow once".

With "When a background session is waiting, switch to it, handle the prompt, then switch back" checked, if a monitored session is not the one on screen, AutoAllow switches to it, confirms the prompt, and switches back. The Claude Desktop window may come to the front briefly while this happens.

If it says "Can monitor, but prompts may be missed while the window is covered", click "Restart in accessibility mode" once when convenient, so prompts are detected even when other windows cover Claude Desktop.

Automatically monitor waiting prompts (off by default)

With "Auto-monitor when a prompt is waiting" checked, whenever a Claude Code window or Claude Desktop session is waiting for confirmation, AutoAllow starts monitoring it and confirms for you, including windows and sessions you did not select. You are asked to confirm when you turn it on, and your choice is remembered.

This option confirms every new prompt. Only turn it on if you trust the work in all of your sessions.

Detect only

Check "Detect only (dry run)" before you start monitoring, and AutoAllow only logs the prompts it finds, without pressing keys or clicking. Use it to see what would be confirmed. The option applies when monitoring starts; after changing it, stop and start monitoring again.

System tray and quitting

Clicking the window's close button minimizes AutoAllow to the system tray, and monitoring keeps running. Double-click the tray icon to open the window again. To quit and stop all monitoring, right-click the tray icon and choose "Quit".

Log and settings files

Daily logs are kept in %LOCALAPPDATA%\AutoAllow\logs, and settings (display language, automatic monitoring) in %LOCALAPPDATA%\AutoAllow\settings.json. These files stay on your computer and are removed when you uninstall the app.

Troubleshooting

My console window is not in the list.
By default only Command Prompt and PowerShell windows running Claude Code are listed. Check "Show all" to see every console. Other terminals, such as Git Bash or WSL windows, are not supported yet.
My Claude Desktop sessions are not in the list.
Make sure the Claude Desktop window is open (not only in the tray) and running in accessibility mode. By default only running or waiting sessions are listed; check "Show all" to see all of them.
The log says "Prompt detected but it does not belong to a selected session, ignored".
When AutoAllow cannot tell for sure that a dialog belongs to a session you selected, it does not click. Add that session to the monitored ones, or turn on "Auto-monitor when a prompt is waiting".
"Restart in accessibility mode" fails.
This button only supports Claude Desktop installed from the Microsoft Store. Wait a moment and try again.
I changed the language but nothing changed.
The language takes effect after AutoAllow restarts: right-click the tray icon, choose "Quit", and open it again.
I want to see what would be confirmed without confirming anything.
Use "Detect only" mode.

AutoAllow でできること

Claude Code と Claude Desktop は、コマンドを実行したりファイルを変更したりする前に許可プロンプトを表示し、あなたの確認を待ちます。AutoAllow は、あなたが選んだウィンドウとセッションでこれらのプロンプトを代わりに承認するため、AI アシスタントが止まって待つ必要がなくなります。

  • Claude Code（コマンド プロンプト、PowerShell、Windows Terminal）：「Do you want to proceed?」というプロンプトが表示されたら、Enter キーを押して既定の「1. Yes」を選びます。
  • Claude Desktop：許可ダイアログが表示されたら、「Allow once」をクリックします。

プロンプトを承認すると、アシスタントが要求したコマンドや操作が実行されます。作業内容を信頼できるセッションだけを監視してください。

始める前に

  • Windows 10（バージョン 1809）以降が必要です。
  • Claude Code は、コマンド プロンプト（cmd）、Windows PowerShell、または PowerShell 7 で実行する必要があります。従来のコンソールウィンドウでも Windows Terminal でも構いません。
  • Claude Desktop は Microsoft Store からインストールし、アクセシビリティモードで実行する必要があります（後述）。
  • AutoAllow は、Claude の英語表示のプロンプトとボタンの文言を認識します。Claude が別の表示言語を使っている場合、プロンプトを認識できないことがあります。

メインウィンドウ

  • 検出されたターゲット：Claude Code を実行しているコンソールウィンドウと、実行中または確認待ちの Claude Desktop セッションです。「すべて表示」にチェックを入れると、すべてのコンソールと待機中のセッションが表示されます。一覧は 3 秒ごとに更新されます。「更新」をクリックしても更新できます。
  • 「状態」列に「● 監視中」と表示されている行は、監視されています。
  • 確認間隔：画面を確認する頻度です（既定は 0.3 秒）。再実行の待機時間：同じプロンプトが画面に表示され続けているとき、2 回の操作の間に空ける最小の秒数です。
  • Claude Desktop 領域：Claude Desktop の状態を表示し、アクセシビリティモードで再起動するボタンがあります。
  • ログ：承認、スキップ、エラーはすべてここに記録されます。緑は成功、赤はエラーまたは確認が必要なことを表します。
  • 「言語」（右下）：表示言語を選びます。アプリを再起動すると反映されます。

Claude Code のコンソールウィンドウを監視する

  1. いつもどおり、コンソールウィンドウで Claude Code を起動します。
  2. AutoAllow の一覧でそのウィンドウを探します（種類は CMD です。タイトルと最終行でウィンドウを区別できます）。
  3. 行を選択して「選択を監視」をクリックするか、行をダブルクリックします。Ctrl キーまたは Shift キーを押しながら選ぶと、複数を選択できます。
  4. 状態が「● 監視中」になると、そのウィンドウに確認プロンプトが表示されるたびに AutoAllow が Enter キーを押し、ログに 1 行書き込みます。

停止するには、行を選択して「選択を停止」をクリックするか、「すべて停止」をクリックします。手動で停止したウィンドウが、自動的に再び監視されることはありません。

Claude Desktop を監視する

  1. Claude Desktop 領域に「アクセシビリティモードで起動中。監視できます」と表示されていることを確認します。アクセシビリティモードがオフと表示されている場合は、「アクセシビリティモードで再起動」をクリックします。Claude Desktop をいったん閉じて開き直すため、先に作業を済ませてください。
  2. 一覧で監視したいセッション（種類は Desktop）を選んで「選択を監視」をクリックします。待機中のセッションをすべて自動で処理したい場合は、「プロンプト待機時に自動で監視」をオンにします（後述）。
  3. 以後、それらのセッションに許可ダイアログが表示されると、AutoAllow が「Allow once」をクリックします。

「バックグラウンドのセッションが待機中なら、切り替えて処理し、元に戻す」にチェックを入れると、監視中のセッションが画面に表示されているものでない場合、AutoAllow はそのセッションに切り替えてプロンプトを承認し、元に戻します。この間、Claude Desktop のウィンドウが一時的に前面に表示されることがあります。

「監視はできますが、ウィンドウが隠れているとプロンプトを見逃す場合があります」と表示された場合は、都合のよいときに一度「アクセシビリティモードで再起動」をクリックしてください。そうすると、ほかのウィンドウが Claude Desktop を覆っていてもプロンプトを検出できます。

待機中のプロンプトを自動で監視する（既定ではオフ）

「プロンプト待機時に自動で監視」にチェックを入れると、Claude Code のウィンドウや Claude Desktop のセッションが確認待ちになるたびに、AutoAllow が監視を開始して代わりに承認します。選択していないウィンドウやセッションも対象です。オンにするときに確認があり、その選択は記憶されます。

このオプションは、新しいプロンプトをすべて承認します。すべてのセッションの作業内容を信頼できる場合にのみ、オンにしてください。

検出のみ

監視を開始する前に「検出のみ（ドライラン）」にチェックを入れると、AutoAllow は見つけたプロンプトをログに記録するだけで、キー入力やクリックは行いません。何が承認されるのかを確認するのに便利です。このオプションは監視の開始時に適用されます。変更した後は、監視をいったん停止してからもう一度開始してください。

システムトレイと終了

ウィンドウの閉じるボタンをクリックすると、AutoAllow はシステムトレイに最小化され、監視は続行されます。トレイのアイコンをダブルクリックすると、ウィンドウが再び開きます。終了してすべての監視を止めるには、トレイのアイコンを右クリックして「終了」を選びます。

ログと設定ファイル

日ごとのログは %LOCALAPPDATA%\AutoAllow\logs に、設定（表示言語、自動監視）は %LOCALAPPDATA%\AutoAllow\settings.json に保存されます。これらのファイルはお使いのコンピューターにのみ保存され、アプリをアンインストールすると削除されます。

AutoAllow가 하는 일

Claude Code와 Claude Desktop은 명령을 실행하거나 파일을 변경하기 전에 권한 프롬프트를 표시하고 사용자의 확인을 기다립니다. AutoAllow는 사용자가 선택한 창과 세션에서 이러한 프롬프트를 대신 승인하므로, AI 어시스턴트가 멈춰서 기다리지 않아도 됩니다.

  • Claude Code(명령 프롬프트, PowerShell, Windows Terminal): "Do you want to proceed?" 프롬프트가 나타나면 Enter 키를 눌러 기본값인 "1. Yes"를 선택합니다.
  • Claude Desktop: 권한 대화 상자가 나타나면 "Allow once"를 클릭합니다.

프롬프트를 승인하면 어시스턴트가 요청한 명령이나 작업이 실행됩니다. 작업 내용을 신뢰할 수 있는 세션만 모니터링하세요.

시작하기 전에

  • Windows 10(버전 1809) 이상이 필요합니다.
  • Claude Code는 명령 프롬프트(cmd), Windows PowerShell 또는 PowerShell 7에서 실행해야 합니다. 기존 콘솔 창이나 Windows Terminal 모두 가능합니다.
  • Claude Desktop은 Microsoft Store에서 설치하고 접근성 모드로 실행해야 합니다(아래 참조).
  • AutoAllow는 Claude 영어 인터페이스의 프롬프트와 버튼 문구를 인식합니다. Claude가 다른 표시 언어를 사용하면 프롬프트를 인식하지 못할 수 있습니다.

기본 창

  • 감지된 대상: Claude Code를 실행 중인 콘솔 창과, 실행 중이거나 확인을 기다리는 Claude Desktop 세션입니다. "모두 표시"를 선택하면 모든 콘솔과 유휴 세션이 표시됩니다. 목록은 3초마다 새로 고쳐지며, "새로 고침"을 클릭해도 됩니다.
  • "상태" 열에 "● 모니터링 중"으로 표시된 행은 모니터링되고 있는 항목입니다.
  • 확인 간격: 화면을 확인하는 빈도입니다(기본값 0.3초). 반복 대기 시간: 같은 프롬프트가 화면에 계속 남아 있을 때 두 동작 사이에 두어야 하는 최소 시간(초)입니다.
  • Claude Desktop 영역: Claude Desktop의 상태를 보여 주며, 접근성 모드로 다시 시작하는 버튼이 있습니다.
  • 로그: 모든 승인, 건너뜀, 오류가 여기에 기록됩니다. 녹색은 성공, 빨간색은 오류이거나 확인이 필요한 내용입니다.
  • "언어"(오른쪽 아래): 표시 언어를 선택합니다. 앱을 다시 시작하면 적용됩니다.

Claude Code 콘솔 창 모니터링

  1. 평소처럼 콘솔 창에서 Claude Code를 시작합니다.
  2. AutoAllow 목록에서 해당 창을 찾습니다(유형은 CMD이며, 제목과 마지막 줄로 창을 구분할 수 있습니다).
  3. 행을 선택하고 "선택 항목 모니터링"을 클릭하거나, 행을 두 번 클릭합니다. Ctrl 또는 Shift 키를 누른 채 선택하면 여러 개를 선택할 수 있습니다.
  4. 상태가 "● 모니터링 중"으로 바뀌면, 해당 창에 확인 프롬프트가 나타날 때마다 AutoAllow가 Enter 키를 누르고 로그에 한 줄을 기록합니다.

중지하려면 행을 선택하고 "선택 항목 중지"를 클릭하거나 "모두 중지"를 클릭합니다. 직접 중지한 창은 자동으로 다시 모니터링되지 않습니다.

Claude Desktop 모니터링

  1. Claude Desktop 영역에 "접근성 모드로 실행 중이며 모니터링할 수 있습니다"라고 표시되는지 확인합니다. 접근성 모드가 꺼져 있다고 표시되면 "접근성 모드로 다시 시작"을 클릭합니다. Claude Desktop이 닫혔다가 다시 열리므로, 하던 작업을 먼저 마치세요.
  2. 목록에서 모니터링할 세션(유형은 Desktop)을 선택하고 "선택 항목 모니터링"을 클릭합니다. 대기 중인 모든 세션을 자동으로 처리하려면 "프롬프트 대기 시 자동 모니터링"을 켜세요(아래 참조).
  3. 그 후 해당 세션에 권한 대화 상자가 나타나면 AutoAllow가 "Allow once"를 클릭합니다.

"백그라운드 세션이 대기 중이면 전환하여 처리한 뒤 다시 돌아오기"를 선택하면, 모니터링 중인 세션이 현재 화면에 있는 세션이 아닐 때 AutoAllow가 해당 세션으로 전환해 프롬프트를 승인한 뒤 다시 돌아옵니다. 이때 Claude Desktop 창이 잠시 앞으로 나올 수 있습니다.

"모니터링은 가능하지만 창이 가려지면 프롬프트를 놓칠 수 있습니다"라고 표시되면, 편할 때 "접근성 모드로 다시 시작"을 한 번 클릭하세요. 그러면 다른 창이 Claude Desktop을 가리고 있어도 프롬프트를 감지할 수 있습니다.

대기 중인 프롬프트 자동 모니터링(기본값: 꺼짐)

"프롬프트 대기 시 자동 모니터링"을 선택하면, Claude Code 창이나 Claude Desktop 세션이 확인을 기다릴 때마다 AutoAllow가 모니터링을 시작하고 대신 승인합니다. 선택하지 않은 창과 세션도 포함됩니다. 켤 때 확인 창이 나타나며, 선택한 내용은 기억됩니다.

이 옵션은 새로운 프롬프트를 모두 승인합니다. 모든 세션의 작업 내용을 신뢰할 수 있을 때만 켜세요.

감지만 하기

모니터링을 시작하기 전에 "감지만 (드라이 런)"을 선택하면, AutoAllow는 찾은 프롬프트를 로그에 기록만 하고 키 입력이나 클릭은 하지 않습니다. 무엇이 승인될지 미리 확인할 때 사용하세요. 이 옵션은 모니터링을 시작할 때 적용되므로, 변경한 후에는 모니터링을 중지했다가 다시 시작하세요.

시스템 트레이와 종료

창의 닫기 버튼을 클릭하면 AutoAllow가 시스템 트레이로 최소화되며 모니터링은 계속됩니다. 트레이 아이콘을 두 번 클릭하면 창이 다시 열립니다. 종료하고 모든 모니터링을 중지하려면 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하고 "종료"를 선택하세요.

로그와 설정 파일

일별 로그는 %LOCALAPPDATA%\AutoAllow\logs에, 설정(표시 언어, 자동 모니터링)은 %LOCALAPPDATA%\AutoAllow\settings.json에 저장됩니다. 이 파일들은 사용자의 컴퓨터에만 남으며, 앱을 제거하면 삭제됩니다.

Was AutoAllow macht

Bevor Claude Code und Claude Desktop einen Befehl ausführen oder Dateien ändern, zeigen sie eine Berechtigungsabfrage an und warten auf Sie. AutoAllow bestätigt diese Abfragen für Sie in den Fenstern und Sitzungen, die Sie auswählen, damit der KI-Assistent nicht anhalten und warten muss.

  • Claude Code (Eingabeaufforderung, PowerShell, Windows Terminal): Sobald die Abfrage „Do you want to proceed?“ erscheint, drückt AutoAllow die Eingabetaste und wählt damit die Vorgabe „1. Yes“.
  • Claude Desktop: Sobald ein Berechtigungsdialog erscheint, klickt AutoAllow auf „Allow once“.

Mit der Bestätigung einer Abfrage erlauben Sie dem Assistenten, den angeforderten Befehl bzw. die angeforderte Aktion auszuführen. Überwachen Sie nur Sitzungen, deren Arbeit Sie vertrauen.

Vor dem Start

  • Erforderlich ist Windows 10 (Version 1809) oder neuer.
  • Claude Code muss in der Eingabeaufforderung (cmd), in Windows PowerShell oder PowerShell 7 laufen, entweder in einem klassischen Konsolenfenster oder im Windows Terminal.
  • Claude Desktop muss über den Microsoft Store installiert sein und im Barrierefreiheitsmodus laufen (siehe unten).
  • AutoAllow erkennt die Abfrage- und Schaltflächentexte der englischen Oberfläche von Claude. Verwendet Claude eine andere Anzeigesprache, werden Abfragen möglicherweise nicht erkannt.

Das Hauptfenster

  • Erkannte Ziele: Konsolenfenster, in denen Claude Code läuft, sowie Claude-Desktop-Sitzungen, die laufen oder auf eine Bestätigung warten. Aktivieren Sie „Alle anzeigen“, um jede Konsole und jede inaktive Sitzung zu sehen. Die Liste wird alle 3 Sekunden aktualisiert, oder klicken Sie auf „Aktualisieren“.
  • Zeilen mit „● Überwacht“ in der Spalte „Status“ werden gerade überwacht.
  • Prüfintervall: wie oft der Bildschirm geprüft wird (standardmäßig 0,3 Sekunden). Wiederholungspause: die Mindestzahl an Sekunden zwischen zwei Aktionen, solange dieselbe Abfrage auf dem Bildschirm bleibt.
  • Bereich für Claude Desktop: zeigt den Zustand von Claude Desktop an, mit einer Schaltfläche zum Neustarten im Barrierefreiheitsmodus.
  • Protokoll: Jede Bestätigung, jedes Überspringen und jeder Fehler wird hier aufgezeichnet. Grün bedeutet Erfolg, rot einen Fehler oder etwas, das Sie prüfen sollten.
  • „Sprache“ (unten rechts): Wählen Sie die Anzeigesprache. Sie wird nach einem Neustart der App wirksam.

Ein Claude-Code-Konsolenfenster überwachen

  1. Starten Sie Claude Code wie gewohnt in einem Konsolenfenster.
  2. Suchen Sie das Fenster in AutoAllow in der Liste (Typ CMD; Fenster lassen sich anhand von Titel und letzter Zeile unterscheiden).
  3. Wählen Sie es aus und klicken Sie auf „Auswahl überwachen“, oder doppelklicken Sie auf die Zeile. Halten Sie Strg oder Umschalt gedrückt, um mehrere auszuwählen.
  4. Sobald der Status „● Überwacht“ anzeigt, drückt AutoAllow die Eingabetaste, wenn in diesem Fenster eine Bestätigungsabfrage erscheint, und schreibt eine Zeile ins Protokoll.

Zum Beenden wählen Sie die Zeile aus und klicken auf „Auswahl beenden“, oder Sie klicken auf „Alle beenden“. Ein Fenster, das Sie von Hand beendet haben, wird nicht automatisch erneut überwacht.

Claude Desktop überwachen

  1. Vergewissern Sie sich, dass im Bereich für Claude Desktop „Läuft im Barrierefreiheitsmodus, bereit zur Überwachung“ steht. Steht dort, dass der Barrierefreiheitsmodus aus ist, klicken Sie auf „Im Barrierefreiheitsmodus neu starten“. Dabei wird Claude Desktop geschlossen und neu geöffnet. Beenden Sie also zuerst, was Sie gerade tun.
  2. Wählen Sie in der Liste die zu überwachenden Sitzungen aus (Typ Desktop) und klicken Sie auf „Auswahl überwachen“. Damit jede wartende Sitzung automatisch bearbeitet wird, aktivieren Sie „Automatisch überwachen, wenn eine Abfrage wartet“ (siehe unten).
  3. Ab dann klickt AutoAllow auf „Allow once“, wenn diese Sitzungen einen Berechtigungsdialog anzeigen.

Ist „Wartet eine Hintergrundsitzung, zu ihr wechseln, die Abfrage bearbeiten und zurückwechseln“ aktiviert und die überwachte Sitzung nicht die gerade angezeigte, wechselt AutoAllow zu ihr, bestätigt die Abfrage und wechselt zurück. Dabei kann das Fenster von Claude Desktop kurz in den Vordergrund kommen.

Steht dort „Überwachung möglich, aber bei verdecktem Fenster können Abfragen verpasst werden“, klicken Sie bei Gelegenheit einmal auf „Im Barrierefreiheitsmodus neu starten“, damit Abfragen auch dann erkannt werden, wenn andere Fenster Claude Desktop verdecken.

Wartende Abfragen automatisch überwachen (standardmäßig aus)

Ist „Automatisch überwachen, wenn eine Abfrage wartet“ aktiviert, beginnt AutoAllow jedes Mal, wenn ein Claude-Code-Fenster oder eine Claude-Desktop-Sitzung auf eine Bestätigung wartet, mit der Überwachung und bestätigt für Sie – auch in Fenstern und Sitzungen, die Sie nicht ausgewählt haben. Beim Einschalten werden Sie um eine Bestätigung gebeten, und Ihre Entscheidung wird gespeichert.

Diese Option bestätigt jede neue Abfrage. Schalten Sie sie nur ein, wenn Sie der Arbeit in allen Ihren Sitzungen vertrauen.

Nur erkennen

Aktivieren Sie „Nur erkennen (Testlauf)“, bevor Sie die Überwachung starten. AutoAllow protokolliert dann nur die gefundenen Abfragen, ohne Tasten zu drücken oder zu klicken. So sehen Sie, was bestätigt würde. Die Option gilt beim Start der Überwachung; nach einer Änderung beenden Sie die Überwachung und starten sie erneut.

Infobereich und Beenden

Ein Klick auf die Schließen-Schaltfläche des Fensters minimiert AutoAllow in den Infobereich der Taskleiste, und die Überwachung läuft weiter. Doppelklicken Sie auf das Symbol im Infobereich, um das Fenster wieder zu öffnen. Um die App zu beenden und jede Überwachung zu stoppen, klicken Sie mit der rechten Maustaste auf das Symbol im Infobereich und wählen „Beenden“.

Protokoll- und Einstellungsdateien

Tägliche Protokolle liegen in %LOCALAPPDATA%\AutoAllow\logs, die Einstellungen (Anzeigesprache, automatische Überwachung) in %LOCALAPPDATA%\AutoAllow\settings.json. Diese Dateien bleiben auf Ihrem Computer und werden beim Deinstallieren der App entfernt.

Ce que fait AutoAllow

Avant d'exécuter une commande ou de modifier des fichiers, Claude Code et Claude Desktop affichent une demande d'autorisation et attendent votre réponse. AutoAllow confirme ces demandes à votre place dans les fenêtres et les sessions que vous choisissez, afin que l'assistant IA n'ait pas à s'arrêter pour attendre.

  • Claude Code (Invite de commandes, PowerShell, Terminal Windows) : lorsque la demande « Do you want to proceed? » apparaît, AutoAllow appuie sur Entrée, ce qui choisit l'option par défaut « 1. Yes ».

Confirmer une demande permet à l'assistant d'exécuter la commande ou l'action demandée. Ne surveillez que des sessions dont vous faites confiance au travail.

Avant de commencer

  • Windows 10 (version 1809) ou ultérieur est requis.

La fenêtre principale

  • Cibles détectées : les fenêtres de console où s'exécute Claude Code, ainsi que les sessions Claude Desktop en cours ou en attente de confirmation. Cochez « Tout afficher » pour voir toutes les consoles et les sessions inactives. La liste est actualisée toutes les 3 secondes, ou cliquez sur « Actualiser ».
  • Les lignes marquées « ● Surveillé » dans la colonne « État » sont en cours de surveillance.
  • Intervalle de vérification : fréquence à laquelle l'écran est vérifié (0,3 seconde par défaut). Délai de répétition : nombre minimal de secondes entre deux actions tant que la même demande reste affichée à l'écran.
  • Zone Claude Desktop : indique l'état de Claude Desktop, avec un bouton pour le redémarrer en mode accessibilité.
  • Journal : chaque confirmation, chaque saut et chaque erreur y est consigné. Le vert signifie un succès ; le rouge, une erreur ou un point à vérifier.
  • « Langue » (en bas à droite) : choisissez la langue d'affichage. Elle prend effet après le redémarrage de l'application.

Pour arrêter, sélectionnez la ligne et cliquez sur « Arrêter la sélection », ou cliquez sur « Tout arrêter ». Une fenêtre que vous avez arrêtée manuellement n'est pas de nouveau surveillée automatiquement.

Surveiller Claude Desktop

  2. Sélectionnez dans la liste les sessions à surveiller (type Desktop) et cliquez sur « Surveiller la sélection ». Pour que toutes les sessions en attente soient traitées automatiquement, activez « Surveiller automatiquement si une demande attend » (voir ci-dessous).
  3. À partir de là, lorsque ces sessions affichent une boîte de dialogue d'autorisation, AutoAllow clique sur « Allow once ».

Si « Si une session en arrière-plan attend, y basculer, traiter la demande, puis revenir » est cochée et qu'une session surveillée n'est pas celle affichée à l'écran, AutoAllow bascule vers elle, confirme la demande, puis revient. La fenêtre de Claude Desktop peut passer brièvement au premier plan pendant ce temps.

Une confirmation vous est demandée lors de l'activation, et votre choix est mémorisé.

Cette option confirme chaque nouvelle demande. Ne l'activez que si vous faites confiance au travail effectué dans toutes vos sessions.

Détection seule

Cochez « Détection seule (simulation) » avant de lancer la surveillance : AutoAllow se contente alors de consigner dans le journal les demandes trouvées, sans appuyer sur des touches ni cliquer. Cela permet de voir ce qui serait confirmé. L'option s'applique au démarrage de la surveillance ; après l'avoir modifiée, arrêtez puis relancez la surveillance.

O que o AutoAllow faz

Antes de executar um comando ou alterar arquivos, o Claude Code e o Claude Desktop mostram uma solicitação de permissão e esperam por você. O AutoAllow confirma essas solicitações para você nas janelas e sessões que você escolher, para que o assistente de IA não precise parar e esperar.

  • Claude Code (Prompt de Comando, PowerShell, Terminal do Windows): quando a solicitação “Do you want to proceed?” aparece, ele pressiona Enter, o que escolhe a opção padrão “1. Yes”.
  • Claude Desktop: quando uma caixa de diálogo de permissão aparece, ele clica em “Allow once”.

Confirmar uma solicitação permite que o assistente execute o comando ou a ação que pediu. Monitore apenas sessões cujo trabalho você considere confiável.

Antes de começar

  • É necessário o Windows 10 (versão 1809) ou posterior.
  • O Claude Code deve ser executado no Prompt de Comando (cmd), no Windows PowerShell ou no PowerShell 7, em uma janela de console clássica ou no Terminal do Windows.
  • O Claude Desktop deve estar instalado pela Microsoft Store e em execução no modo de acessibilidade (veja abaixo).
  • O AutoAllow reconhece os textos das solicitações e dos botões da interface em inglês do Claude. Se o Claude usar outro idioma de exibição, as solicitações podem não ser reconhecidas.

A janela principal

  • Destinos detectados: janelas de console executando o Claude Code e sessões do Claude Desktop que estão em execução ou aguardando confirmação. Marque “Mostrar tudo” para ver todos os consoles e as sessões inativas. A lista é atualizada a cada 3 segundos, ou clique em “Atualizar”.
  • As linhas marcadas com “● Monitorando” na coluna “Status” estão sendo monitoradas.
  • Intervalo de verificação: com que frequência a tela é verificada (0,3 segundo por padrão). Espera entre repetições: o número mínimo de segundos entre duas ações enquanto a mesma solicitação continua na tela.
  • Área do Claude Desktop: mostra o estado do Claude Desktop, com um botão para reiniciá-lo em modo de acessibilidade.
  • Log: cada confirmação, omissão ou erro é registrado aqui. Verde significa sucesso; vermelho significa um erro ou algo que merece verificação.
  • “Idioma” (canto inferior direito): escolha o idioma de exibição. Ele passa a valer depois que você reinicia o aplicativo.

Monitorar uma janela de console do Claude Code

  1. Inicie o Claude Code em uma janela de console como de costume.
  2. No AutoAllow, localize a janela na lista (tipo CMD; você pode distinguir as janelas pelo título e pela última linha).
  3. Selecione-a e clique em “Monitorar seleção”, ou clique duas vezes na linha. Mantenha Ctrl ou Shift pressionado para selecionar várias.
  4. Quando o status mostrar “● Monitorando”, o AutoAllow pressiona Enter sempre que uma solicitação de confirmação aparece nessa janela e grava uma linha no log.

Para parar, selecione a linha e clique em “Parar seleção”, ou clique em “Parar tudo”. Uma janela que você parou manualmente não volta a ser monitorada automaticamente.

Monitorar o Claude Desktop

  1. Confirme que a área do Claude Desktop diz “Em modo de acessibilidade, pronto para monitorar”. Se disser que o modo de acessibilidade está desativado, clique em “Reiniciar em modo de acessibilidade”. Isso fecha e reabre o Claude Desktop, então termine antes o que estiver fazendo.
  2. Selecione na lista as sessões a monitorar (tipo Desktop) e clique em “Monitorar seleção”. Para que toda sessão em espera seja tratada automaticamente, ative “Monitorar automaticamente quando houver solicitação pendente” (veja abaixo).
  3. A partir daí, quando essas sessões mostrarem uma caixa de diálogo de permissão, o AutoAllow clica em “Allow once”.

Com “Se uma sessão em segundo plano estiver esperando, ir até ela, tratar a solicitação e voltar” marcada, se uma sessão monitorada não for a que está na tela, o AutoAllow muda para ela, confirma a solicitação e volta. A janela do Claude Desktop pode passar rapidamente para o primeiro plano enquanto isso acontece.

Se aparecer “Dá para monitorar, mas solicitações podem passar despercebidas com a janela coberta”, clique uma vez em “Reiniciar em modo de acessibilidade” quando for conveniente, para que as solicitações sejam detectadas mesmo quando outras janelas cobrirem o Claude Desktop.

Uma confirmação é pedida quando você ativa a opção, e sua escolha é lembrada.

Esta opção confirma todas as novas solicitações. Ative-a somente se você confiar no trabalho de todas as suas sessões.

Só detectar

Marque “Só detectar (simulação)” antes de iniciar o monitoramento, e o AutoAllow apenas registra no log as solicitações que encontrar, sem pressionar teclas nem clicar. Use para ver o que seria confirmado. A opção vale quando o monitoramento é iniciado; depois de alterá-la, pare e inicie o monitoramento novamente.

Bandeja do sistema e como sair

Что делает AutoAllow

Перед выполнением команды или изменением файлов Claude Code и Claude Desktop показывают запрос разрешения и ждут вашего ответа. AutoAllow подтверждает такие запросы за вас в тех окнах и сеансах, которые вы выбрали, поэтому ИИ-ассистенту не приходится останавливаться и ждать.

  • Claude Code (Командная строка, PowerShell, Windows Terminal): когда появляется запрос «Do you want to proceed?», программа нажимает Enter, что выбирает вариант по умолчанию «1. Yes».
  • Claude Desktop: когда появляется диалог разрешения, программа нажимает «Allow once».

Подтверждение запроса позволяет ассистенту выполнить команду или действие, которое он запросил. Следите только за теми сеансами, работе которых вы доверяете.

Перед началом работы

  • Требуется Windows 10 (версия 1809) или новее.
  • Claude Code должен работать в Командной строке (cmd), Windows PowerShell или PowerShell 7 — в классическом окне консоли или в Windows Terminal.
  • Claude Desktop должен быть установлен из Microsoft Store и запущен в режиме специальных возможностей (см. ниже).
  • AutoAllow распознаёт текст запросов и кнопок английского интерфейса Claude. Если Claude использует другой язык интерфейса, запросы могут не распознаваться.

Главное окно

  • Найденные цели: окна консоли с Claude Code и сеансы Claude Desktop, которые выполняются или ждут подтверждения. Установите флажок «Показать все», чтобы увидеть все консоли и неактивные сеансы. Список обновляется каждые 3 секунды; можно также нажать «Обновить».
  • Строки с пометкой «● Мониторинг» в столбце «Состояние» находятся под наблюдением.
  • Интервал проверки: как часто проверяется экран (по умолчанию 0,3 секунды). Пауза между повторами: минимальное число секунд между двумя действиями, пока один и тот же запрос остаётся на экране.
  • Область Claude Desktop: показывает состояние Claude Desktop и содержит кнопку для его перезапуска в режиме специальных возможностей.
  • Журнал: здесь записывается каждое подтверждение, пропуск или ошибка. Зелёный цвет означает успех; красный — ошибку или то, что стоит проверить.
  • «Язык» (справа внизу): выбор языка интерфейса. Изменение вступает в силу после перезапуска приложения.

Мониторинг окна консоли с Claude Code

  1. Запустите Claude Code в окне консоли как обычно.
  2. В AutoAllow найдите это окно в списке (тип CMD; окна можно различить по заголовку и последней строке).
  3. Выберите его и нажмите «Следить за выбранными» или дважды щёлкните строку. Удерживайте Ctrl или Shift, чтобы выбрать несколько.
  4. Когда в столбце состояния появится «● Мониторинг», AutoAllow будет нажимать Enter каждый раз, когда в этом окне появляется запрос подтверждения, и записывать строку в журнал.

Чтобы остановить слежение, выберите строку и нажмите «Остановить выбранные» или нажмите «Остановить все». Окно, которое вы остановили вручную, автоматически снова под наблюдение не берётся.

Мониторинг Claude Desktop

  1. Убедитесь, что в области Claude Desktop написано «Запущен в режиме специальных возможностей, можно следить». Если сообщается, что режим специальных возможностей отключён, нажмите «Перезапустить в режиме специальных возможностей». Claude Desktop будет закрыт и открыт заново, поэтому сначала завершите текущие дела.
  2. Выберите в списке сеансы для слежения (тип Desktop) и нажмите «Следить за выбранными». Чтобы все ожидающие сеансы обрабатывались автоматически, включите «Автомониторинг при ожидающем запросе» (см. ниже).
  3. После этого, когда в этих сеансах появляется диалог разрешения, AutoAllow нажимает «Allow once».

Если установлен флажок «Если фоновый сеанс ждёт, переключиться на него, обработать запрос и вернуться», то когда отслеживаемый сеанс не является открытым на экране, AutoAllow переключается на него, подтверждает запрос и возвращается обратно. В это время окно Claude Desktop может ненадолго выйти на передний план.

Если написано «Следить можно, но пока окно перекрыто, запросы могут быть пропущены», один раз нажмите «Перезапустить в режиме специальных возможностей», когда вам удобно, — тогда запросы будут обнаруживаться, даже если Claude Desktop закрыт другими окнами.

Автоматический мониторинг ожидающих запросов (по умолчанию выключен)

Если установлен флажок «Автомониторинг при ожидающем запросе», то каждый раз, когда окно Claude Code или сеанс Claude Desktop ждёт подтверждения, AutoAllow начинает следить за ним и подтверждает запрос за вас, в том числе в окнах и сеансах, которые вы не выбирали. При включении вас попросят подтвердить выбор, и он будет запомнен.

Этот параметр подтверждает каждый новый запрос. Включайте его только если вы доверяете работе во всех своих сеансах.

Только обнаружение

Установите флажок «Только обнаружение (пробный запуск)» до начала мониторинга, и AutoAllow будет только записывать найденные запросы в журнал, не нажимая клавиши и не щёлкая мышью. Так можно увидеть, что было бы подтверждено. Параметр применяется при запуске мониторинга; после его изменения остановите мониторинг и запустите снова.

Область уведомлений и выход

Нажатие кнопки закрытия окна сворачивает AutoAllow в область уведомлений, мониторинг при этом продолжается. Дважды щёлкните значок в области уведомлений, чтобы снова открыть окно. Чтобы выйти и остановить весь мониторинг, щёлкните значок в области уведомлений правой кнопкой мыши и выберите «Выход».

Журнал и файлы настроек

Ежедневные журналы хранятся в %LOCALAPPDATA%\AutoAllow\logs, а настройки (язык интерфейса, автоматический мониторинг) — в %LOCALAPPDATA%\AutoAllow\settings.json. Эти файлы остаются на вашем компьютере и удаляются при удалении приложения.
